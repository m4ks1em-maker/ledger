Ledger

Кто тебя зарепортил и на какой минуте

Ledger разбирает реплеи Dota 2 и показывает каждый репорт на таймлайне: от союзников и от врагов. Вставь Steam ID, и реплеи скачаются сами, без входа в Steam.

Купить ключпиши в Telegram @m4ks1em Скачать с GitHub

Как начать

  1. Купи ключНапиши в Telegram, получишь ключ вида LDG-XXXX-XXXX-XXXX-XXXX.
  2. Скачай LedgerGitHub → Code → Download ZIP, распакуй в любую папку.
  3. Поставь Node.jsВерсия LTS с nodejs.org, обычная установка.
  4. Запустиsetup.bat один раз, потом start.bat. Вставь ключ, и готово.

Один ключ работает на одном компьютере. Реплеи разбираются у тебя на ПК, наружу уходит только проверка ключа.
